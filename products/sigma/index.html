Asynthetic / SIGMA

Think spatially about media.

SIGMA Canvas Studio is a high-performance, local-first infinite spatial canvas designed for organizing, visualizing, and editing media assets. From video to high-resolution imagery on an effectively unbounded workspace instead of a folder stree.

Local, offline use Rust + Tauri Desktop app Apache 2.0

Capabilities

What SIGMA actually does today

Grounded in the current codebase and README, separated from what's in progress or only planned.

01 · Spatial canvas

Drop media into an unbounded workspace

Images and video are arranged directly on an effectively infinite canvas rather than sorted into folders. Position and grouping become the organizing structure.

  • Drag, drop, and freely arrange video and image clips
  • Pan and zoom across a non-linear workspace
  • Item count and canvas state tracked in the HUD
02 · Media-native interaction

Video and images act as canvas objects

Media that plays and is editable in place. Each clip carries its own controls for framing and playback.

  • Frame-accurate scrubbing
  • A/B loop points for reviewing a segment repeatedly
  • Resize and crop directly on the canvas
  • Per-item toolbar for quick edits

03 · Local-first pipeline

Rust handles media, not a remote service

Decoding, frame access, and export run through a Rust backend reached over Tauri's IPC boundary, where the media stays on the machine it's opened on.

  • No server or account required to use the canvas
  • Desktop V-Sync-paced playback with a low memory footprint
  • FFmpeg on the local PATH powers export
04 · Persistent workflows

Save and reload a canvas layout

A canvas configuration, every item's position, crop, and loop points, can be saved and loaded back. Such that a workspace can be reused as a template.

  • Save / Load canvas state
  • Reusable spatial workspaces for recurring tasks
05 · Export

Pull work back out as standard files

Export is intentionally basic today: H.264 output for marked A/B loops, still screenshots, and cropped segments, enough to get a clip out of the canvas and into another tool.

  • H.264 export for A/B loop ranges
  • Screenshot export
  • Cropped-segment export
06 · ComfyUI integration

Watch generation output land on the canvas

Why spatial

Where a canvas beats a folder tree

Use cases the project was built around, where just the situations where a linear file browser breaks down.

Film editing

Lay out selects, references, and takes spatially to plan a cut before touching a timeline editor.

Dataset triage

Scan and sort large batches of clips or images for ML/dataset review by eye, arranging them by similarity or quality instead of scrolling a directory listing.

Moodboarding

Pull in massive video clips and stills side by side to build a visual reference board without pre-cropping everything down to thumbnails.

Research boards

Assemble large visual research or evidence collections where spatial position and proximity carry meaning a flat list can't.

Generative workflows

Drop a batch of media down and think about it spatially, including outputs streamed in from a connected generation pipeline.

Roadmap

Studio today, Render Lab as direction

SIGMA's README draws a clear line between the current Studio edition and a planned Render Lab tier. Nothing in the right column ships yet.

Studio

Current
  • Single infinite canvas
  • Native rendering through Tauri's WebView
  • Standard JPG / MP4 workflows
  • 1080p-oriented H.264 export
  • Shapes, pen, text, color, and border annotation
  • ComfyUI browser and execution (WIP)

Render Lab

Planned / exploratory
  • Multiple, project-based workspaces
  • wgpu-accelerated direct render pipeline
  • 4K+, ProRes, and wide-gamut export
  • Live asset streaming
  • RAW, 3D (OBJ/STL), and EXR asset support
  • Asset tagging, executable pipelines, masking
  • Cloud compute and folder-watching workflows
